# Crypto dashboard

A live crypto market dashboard: real-time prices, candlestick charts, order book and
recent trades, using Gate's public market data API.

Work in progress. See [docs/brief.md](docs/brief.md) for the scope and
[docs/architecture.md](docs/architecture.md) for the technical decisions.

## Getting started

Requirements: Node.js 22 or newer, pnpm 10.

```sh
pnpm install
pnpm dev
```

> Not financial advice. This project is a technical demo.
